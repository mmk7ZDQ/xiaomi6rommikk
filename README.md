# 小米 6（MI 6 / sagit）· RestlessOS 16 刷机包

**系统：RestlessOS 16.0.0（Android 16，GrapheneOS 血统）**
**底层：LineageOS 22.2（Android 15 的 vendor / 内核 / recovery）**

专门给小米 6 拼的一套。刷完没有 Google 服务、没有广告、没有厂商全家桶，
界面干净，隐私优先。

---

## 先选路线

两种刷法，**任选一种**。不知道自己该选哪个就看这张表：

| | 方式 A：ROM 包刷机 | 方式 B：拆包直刷 |
|---|---|---|
| 难度 | ⭐ 简单 | ⭐⭐ 中等 |
| 手机界面 | 要点几下恢复模式 | 全程终端敲命令 |
| 速度 | 慢（约 15 分钟） | 快（约 8 分钟） |
| 掉线风险 | 中（一根线传 1.3 GB） | 低（分块重传更容易恢复） |
| 适合谁 | **第一次刷机** | 刷过一次 / 方式 A 失败过 |

> **建议第一次刷选方式 A。** 方式 B 是我自己实测时用的，因为 sideload 在我这儿
> 老是到 39% 掉线。你那边线好就 A，线差就 B。

## 刷之前必须知道的三件事

1. **会清空手机全部数据。** 照片、微信、通讯录，全没了。先备份。
2. **bootloader 必须已解锁。** 没解锁刷不进去。解锁要等小米 72 小时。
3. **这不是 GrapheneOS。** 它是把 GrapheneOS 的用户空间打成通用系统镜像，
   vendor / 内核 / 固件还是厂商的。安全模型不完整，别拿它当"绝对安全"的手机。

---

## 包里有什么

| 文件 | 是什么 | 刷到哪 |
|---|---|---|
| `boot.img` | 内核 + 启动脚本 | `boot` 分区 |
| `system-padded.img` | 整个系统（5 GiB） | `system` 分区 |
| `vendor.img` | 驱动（相机/信号/指纹靠它） | **`cust` 分区** |
| `recovery.img` | 恢复模式 | `recovery` 分区 |
| `sagit-RestlessOS-*.zip` | 上面全部打成一个包 | 方式 A 用 |

> ⚠️ `vendor.img` 要刷到 **`cust`**，不是 `vendor`。小米 6 的 vendor 分区就叫 cust，
> 这是它的怪癖。刷错了相机和指纹全废。

---

## 风险

刷机有风险，最坏情况是开不了机。但这套流程**完全不碰** `bootloader` / `modem` /
`persist` 这些要命的分区，所以**几乎不可能真变砖** —— 开不了机就重刷。

后果自负。
