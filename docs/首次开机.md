# 首次开机 · 设置指南

刷完重启后，等 2-5 分钟（第一次开机特别慢）。这里说开机之后怎么弄。

---

## 怎么确认它起来了

电脑终端：

```bash
lsusb | grep 2717
```

看到 `2717:ff40` = 系统已经在跑了。

> `adb devices` 这时候通常**看不到设备** —— 见下面「打开 USB 调试」。

---

## 开机向导

按屏幕走：

1. **语言** → 简体中文（或你要的）
2. **WiFi** → 连上（刷机包是完整的，不需要联网完成设置，但联网方便后面装 App）
3. **时间** → 自动获取
4. **PIN / 密码 / 图案** → 设一个（这个系统安全优先，建议设）
5. **指纹** → 可以现在录，也可以跳过

> 有些版本会问"要不要恢复数据"，选**不恢复**（这是全新系统，没东西可恢复）。

## 按键怎么用

**这个系统的虚拟导航栏被关掉了**（见[我改了什么](我改了什么.md)），
因为小米 6 有实体键：

| 你要干什么 | 按哪里 |
|---|---|
| **返回** | 屏幕下方**左侧**按键 |
| **回桌面** | **指纹键**按一下（不用解锁，轻触就行） |
| **多任务 / 最近应用** | 屏幕下方**右侧**按键 |
| **音量** | 侧面音量键 |
| **电源** | 侧面电源键 |

> 左右键能不能对调？设置里有"按键"选项可以改。

### 想要虚拟导航栏回来？

设置 → 系统 → 手势 → 系统导航方式，可以切：

- **手势导航** — 屏幕底部滑动
- **三键导航** — 虚拟的返回/桌面/多任务
- **双键导航** — 简化的

切换后需要重启生效（有时不用）。

> 能切是因为我**没有删**那些 overlay APK。如果切不了说明包不对。

## 打开 USB 调试（要用 adb 才需要）

RestlessOS（跟原版 GrapheneOS 一样）**默认关 USB 调试**，这是安全设计。

1. 设置 → 关于手机
2. 连点 **「版本号」7 次** → 提示"你现在是开发者了"
3. 返回 → 系统 → **开发者选项**
4. 找到 **USB 调试** → 打开
5. 插线，手机会弹「允许 USB 调试吗」→ 勾"一律允许"→ 允许

验证：

```bash
adb devices
# 应该看到 a5610dac  device
```

## 装 App

### 系统自带的商店

桌面找 **Apps**（图标是个 G 形，但其实是 GrapheneOS 的 App Store，包名
`app.grapheneos.apps`）。

里面是一些精选的开源 App。

### F-Droid（推荐）

开源 App 最大的仓库：

1. 电脑下 <https://f-droid.org/F-Droid.apk>
2. 传到手机（数据线拷，或者用 `adb push F-Droid.apk /sdcard/`）
3. 手机上用文件管理器点开装（会提示"允许安装未知应用"，同意）

装好之后可以在 F-Droid 里搜：
- **Aurora Store** — 匿名访问 Google Play 的客户端（不装 GMS 也能下 Play 的 App）
- **NewPipe** — 看 YouTube 不要广告
- **Organic Maps** — 离线地图
- **VLC** — 播放器
- **Termux** — 终端

### 已有的 APK

从电脑传：

```bash
adb push 某个app.apk /sdcard/Download/
```

然后在手机上用文件管理器打开 `Download` 目录点安装。

## 关于 Google 服务

**没有，也不建议装。**

这是 GrapheneOS 血统的系统，核心设计就是不用 Google。装了 GMS 等于白刷。

需要 Play 商店的 App，用 **Aurora Store**（F-Droid 里有），它匿名下载 Play 的 App，
不需要登录 Google 账号。

## 常见问题

### Q: 屏幕底下没有导航条，我以为坏了

**不是。** 这是故意的。用实体键（见上面「按键怎么用」）。

### Q: 指纹键按了没反应

去 设置 → 安全 → 指纹 里录一遍。录完之后轻触就能解锁/回桌面。

### Q: 相机打不开

vendor 没刷对。回[出问题怎么办 · 症状 7](出问题怎么办.md#症状-7刷完开机了但相机--指纹--信号不能用)。

### Q: 没有信号 / 打不了电话

同上，vendor 问题。检查：

```bash
adb shell getprop gsm.version.baseband
```

应该有值（比如 `AT20-0506_2249_2f010e6`）。空的说明 vendor 没挂上。

### Q: 能装微信吗

能。但见[出问题怎么办 · 症状 10](出问题怎么办.md#症状-10微信--支付宝--银行-app-说设备不安全)。

### Q: 系统更新怎么办

这个包不会自动更新（没有 OTA 服务器）。想升级只能重新刷。

> 升级时如果**不清 data**，理论上能保留数据，但跨版本不保证。建议每次升级都备份。

### Q: 能不能 OTA

不能。RestlessOS GSI 没有 OTA 基础设施。

## 确认一切正常（检查清单）

```bash
# 需要先开 USB 调试

# 1. 系统版本
adb shell getprop ro.build.version.release     # 期望 16
adb shell getprop ro.build.version.sdk         # 期望 36
adb shell getprop ro.treble.enabled            # 期望 true

# 2. 指纹（说明是哪个系统）
adb shell getprop ro.system.build.fingerprint
# 期望类似 google/treble_arm64_bvN/tdgsi_arm64_ab:16/...

# 3. 基带（说明 vendor 正常）
adb shell getprop gsm.version.baseband
# 期望类似 AT20-0506_2249_2f010e6

# 4. 导航栏属性（说明我的改动生效了）
adb shell getprop persist.sys.phh.mainkeys     # 期望 1
adb shell getprop qemu.hw.mainkeys             # 期望 1

# 5. SELinux
adb shell getenforce                           # 期望 Enforcing
```

全部对得上就完美了。
